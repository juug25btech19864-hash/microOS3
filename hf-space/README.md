## 🌟 About MicroOS
MicroOS is an ultra-lightweight bootable x86_64 Linux operating system engineered from the ground up to operate within a **strict 50 MB hard ISO ceiling**.

### Features:
- **Interactive Modern Desktop Environment**: 22 native applications, window management, multitasking bar, and live telemetry.
- **Real Wi-Fi Hardware Integration**: Detects host Wi-Fi 6 (Realtek RTL8852BE) and surrounding SSIDs (`MOJO-JAN-C1-F9`, etc.).
- **Built-in Micro Arcade Suite**: 8 classic games (Snake, Tetris, Pong, Minesweeper, 2048, and more).
- **Pristine Bash Terminal**: Custom shell prompt `srivas@microos:~$ ` with 30+ native commands.
- **Dual Boot Support**: BIOS MBR + UEFI x86_64 hybrid bootable ISO under 33 MB.
